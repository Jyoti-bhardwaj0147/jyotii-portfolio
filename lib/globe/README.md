Land dots and the static fallback are sampled from Natural Earth's 1:110m land polygons (public domain).

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/

The latitude grid is spaced at 0.85 degrees; longitude spacing is adjusted by cosine(latitude). Polygon holes are excluded. Coordinates are stored as [latitude, longitude]. No geographic data is fetched at runtime.
